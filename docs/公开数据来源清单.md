## 采集方法与可信度声明

1. **PDF 获取方式**：本次采集使用 `web_fetch` 时，所有 PDF 均返回 `unsupported content type "application/pdf"`，无法直接读取。
   因此改为**本地下载 + 本地文字抽取**：用 Python `urllib` 下载 PDF 原文，用 `pypdf 6.19.0` 抽取文字层，
   写入 UTF-8 文本文件后再逐条核对。所有 PDF 缓存与抽取脚本保留在 `data/raw/_pdf/`，可复查。
2. **每个数字都来自原文**：`公开数据_原始提取.json` 中每条指标都带 `quote`（原文照抄）与 `source_id`（可点击 URL）。
   本文档中的所有数值均由该 JSON 程序化生成，与 JSON 完全一致，不存在两处不一致的风险。
3. **不采用搜索摘要填空**：搜索引擎摘要仅用于定位 PDF 直链，未作为任何数值的来源。
4. **二手转载一律标注**：唯一一处二手来源为「银行业金融机构法人数量 4070 家」（S28），已在 JSON 的 `note` 中标注【来自二手转载】。
5. **自行计算一律标注**：凡本项目计算得出的数值，JSON 中带 `derived: true`，并在 `note` 中写明算式。
6. **重要口径变化提示**（影响时序建模，务必注意）：
   > 人民银行《支付体系运行总体情况》**自 2025 年第一季度报告起改版**，删除了「人均持有银行卡／信用卡」「每万人拥有 ATM 机具」
   > 「银联跨行支付系统联网特约商户」「联网 POS 机具」「每万人拥有联网 POS 机具」「银行卡卡均／笔均消费金额」「电话支付」等明细项。
   > 因此这些指标在 2025Q1 及以后为**报告未披露**（不是数据缺失错误），做同比时需专门处理。
