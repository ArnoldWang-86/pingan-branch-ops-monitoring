Agent 能力边界（如实说明）
· 支持的操作为白名单制：Agent 只能从预定义操作里选择并填参数， 不会执行任意代码——这样从结构上排除了代码注入与幻觉带来的风险。
· 不填 API Key 时，Agent 用关键词+语义规则匹配内置模板；匹配不到会明确告知， 而不是硬凑一个答案。
· 生成的 Excel 由浏览器端 SheetJS 现场构造，不含任何宏，可直接用 Excel / WPS 打开。
· 数据为模拟数据，仅用于演示方法，不可用于推断任何真实银行。
